# Bash-эмулятор на Python — Этап 1

Минимальный прототип эмулятора командной оболочки с графическим интерфейсом.

## Цель этапа

Создать REPL-прототип: поддержать диалог с пользователем через GUI, реализовать парсер ввода и команды-заглушки.

## Реализованные требования

| № | Требование | Реализация |
|---|---|---|
| 1 | GUI | Окно на Tkinter с областью вывода и полем ввода |
| 2 | Заголовок окна содержит имя VFS | `t_window.title(f"VFS: {VFS_NAME}")` |
| 3 | Простой парсер ввода по пробелам | Функция `parse_command` |
| 4 | Команды-заглушки `ls`, `cd` | Функции `cmd_ls`, `cmd_cd` |
| 5 | Команда `exit` | Функция `cmd_exit` |
| 6 | Интерактивная демонстрация | Запуск и ввод команд в поле |
| 7 | Коммит | `feat: add REPL prototype with stub commands` |

## Запуск

```bash
python3 src/EmuBash.py
