# Bash-эмулятор на Python

Эмулятор командной оболочки UNIX-подобной ОС с графическим интерфейсом.

## Общее описание

Программа эмулирует работу командной строки UNIX-подобной ОС: принимает команды пользователя, разбирает их на имя команды и аргументы, выполняет их и отображает результат. Ввод-вывод реализован через графический интерфейс на Tkinter: окно содержит область вывода и строку ввода с приглашением в стиле bash (`user@host:cwd$`).

Проект разрабатывается поэтапно:

- **Этап 1. REPL.** Минимальный прототип с GUI, парсером ввода и командами-заглушками.
- **Этап 2. Конфигурация.** Параметры командной строки, TOML-конфиг, стартовый скрипт, отладочный вывод.
- **Этап 3. VFS.** Виртуальная файловая система в памяти на основе CSV.

Текущее состояние репозитория соответствует **Этапу 2**.

### Язык и стек

- Python 3.9+
- Tkinter (стандартная библиотека)
- `tomllib` (Python 3.11+) или `tomli` (для 3.9–3.10)
- `argparse`, `csv`, `base64`, `os`, `socket`, `getpass` — стандартная библиотека

## Описание всех функций и настроек

### Функции

**GUI и ввод-вывод**

| Функция | Назначение |
|---|---|
| `build_prompt` | Сборка приглашения `user@host:cwd$` |
| `t_window_init` | Создание главного окна, области вывода, поля ввода |
| `output_write` | Вывод строки в область вывода с прокруткой вниз |
| `parse_command` | Разбиение строки ввода на команду и аргументы по пробелам |
| `enter_handle_process` | Обработка нажатия клавиши Enter в поле ввода |
| `dispatch_command` | Определение команды и вызов соответствующего обработчика |

**Команды (заглушки на этапе 2)**

| Функция | Назначение |
|---|---|
| `cmd_ls` | Заглушка `ls` — выводит имя команды и список аргументов |
| `cmd_cd` | Заглушка `cd` — выводит имя команды и список аргументов |
| `cmd_exit` | Закрытие приложения |

**Конфигурация**

| Функция | Назначение |
|---|---|
| `parse_cli_args` | Разбор параметров командной строки |
| `load_toml` | Чтение TOML-файла |
| `resolve_paths` | Преобразование относительных путей из TOML в абсолютные от папки конфига |
| `merge_config` | Слияние CLI и TOML с приоритетом TOML |
| `print_debug_config` | Отладочный вывод параметров с указанием источника |
| `run_startup_script` | Выполнение стартового скрипта с остановкой на первой ошибке |
| `setup_config` | Сборка итоговой конфигурации из CLI и TOML |
| `main` | Точка входа |

### Настройки

**Константы**

| Константа | Значение | Назначение |
|---|---|---|
| `T_WINDOW_W` | 1000 | Ширина окна |
| `T_WINDOW_H` | 800 | Высота окна |
| `T_WINDOW_PAD_X` | 50 | Отступ окна по X |
| `T_WINDOW_PAD_Y` | 50 | Отступ окна по Y |
| `INPUT_PAD_X` | 8 | Горизонтальный отступ поля ввода |
| `INPUT_PAD_Y` | 8 | Вертикальный отступ поля ввода |
| `VFS_NAME` | `my_vfs` | Имя VFS (используется в заголовке окна) |

**Параметры командной строки**

| Флаг | Назначение |
|---|---|
| `--vfs-root <path>` | Путь к физическому расположению VFS |
| `--startup-script <path>` | Путь к стартовому скрипту |
| `--config <path>` | Путь к конфигурационному файлу TOML |
